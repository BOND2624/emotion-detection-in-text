# Emotion Detection in Text using DistilBERT

This project implements emotion detection in text using the DistilBERT model. It can classify text into different emotional categories with high accuracy.

## Overview

The project uses DistilBERT, a distilled version of BERT that retains 97% of its language understanding capabilities while being 40% smaller. The model is fine-tuned on an emotion dataset to classify text into different emotional categories.

## Features

- Text preprocessing and cleaning
- DistilBERT-based emotion classification
- Support for multiple emotion categories
- Jupyter notebook implementation
- Pre-trained model support
